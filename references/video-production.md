# 课程视频制作细则

在素材核对、Demo和正式批次阶段按需读取。使用当前可用、可验证的录屏、剪辑与MG工具，不绑定某台电脑或历史项目。

## 素材与真实性

- 阅读剧本和课件，再看图片、视频与UI；素材清单中区分原稿、教学整理、错误输出和修订结果。
- 截图只支撑图中可见内容。例如攥拳图不能证明同时发生了拦人动作；可用原文和MG解释动作关系。
- 优先取已经确认的原演示会话，避免重新生成不同结果却强套旧台词。无法取得操作录屏时，提出真实截图讲解的替代，并纳入视频方式确认。
- 裁去账号、无关历史与临时浮层，保留工具上下文；需要看字时放大区域，不把整张竖屏界面缩到读不清。
- 缺口清单写清对应字幕、所需素材、清晰度或角度、是否可用MG代替。已有素材足够的部分继续整理。
- 代操作沿用会话授权与平台要求，不伪造登录、点击、生成过程或结果。连接不可用时说清缺口，不声称已经调用飞书或已经录屏。

## 主时间线与画面对应

每条字幕保留稳定ID、绝对起止时间，并建立对应记录，例如：

```json
{
  "cue_id": 18,
  "start_ms": 84394,
  "end_ms": 88302,
  "meaning": "引入五个概念",
  "asset": "concept-map",
  "region": "overview",
  "event": "先展示全图，再按讲解突出节点"
}
```

这是格式示例，不是具体课程的固定内容或时间。

- “上一课”显示回顾，“今天写剧本”聚焦写作，“这张材料截图”显示材料图，不跳到后面章节。
- 气口中停留当前重点或保留轻微动作，不因字幕消失就变黑、换页或提前弹出下一句的结果。
- 一句中多项内容可按语义顺序推进；保留等待、看片和练习时间，答案只在讲师点评或解答的对应字幕出现。
- 批次内部可用局部零点，但数据保留绝对主时间，交付时注明放置点。
- 优先完整句末切分；固定时间跨句时，让画面和字幕完整延续到下一批，不截词、不重复。
- 视频按帧量化时间。记录实际帧率、片长和少量帧误差，以帧号计算接续，不按四舍五入的整秒累积排片。

## MG与画面组织

沿用确认的配色、排版与人物风格。抽象关系用图解，具体事实用资料；人物、场景、道具帮助理解当前问题，不为填空白而随意加入。

同一单元保持稳定空间，优先采用人物动作、小场景变化、连线生长、局部放大和对照标记。避免每条字幕切整页，也避免人物一直无意义晃动。

MG不能增加原案例没有的决定、台词或结果。原稿与工具输出有差异时，显示讲师正在分析的那份材料，不把错误输出当成已经纠正。

## 清理制作标注

检查标题、副标题、角标、页脚、图旁小字、UI浮层和转场中的淡出文字。可搜索源码中的 `SRT`、`气口`、`核对`、`MG示意`、`待补`、`同步版`、`工具名称介绍`，逐项判断是否真是课程内容。

- 删除“SRT气口同步”“按新版时间线”“教学MG示意”“制作核对”等制作标注，不作水印或页脚。
- 路径、素材编号、渲染日志、检查信息留在工作文件，不入口播或画面。
- 原稿、演示新增、修改前后、参考答案等如果是本课知识点，要保留，不能机械删除所有“演示”字样。
- 不因清理制作标注去掉用户要求保留的署名或必要归属。

## 渲染与验收

- 先检查字体、编解码器和渲染能力，用短片验证中文、尺寸与字幕设置。
- 采用有限缓存和流式写帧，不把整课高清帧或所有页面常驻内存。保守设置编码线程和并发；遇内存不足降低占用，不反复重启同样的大任务。
- 保存主时间范围、帧数和完成位置。中断后仅复用完整解码且帧数核实的前缀，从下一准确帧续接；拼接后再检查，不交付半成品。
- 修订另存版本，保留原确认成片；统一清理多个片段时给替换说明和时间保持检查。

每批检查：实际可播放与完整解码；片长、帧数、分辨率、音轨和字幕设置；起止及接缝；字幕触发、关键操作；中文字与图片清晰度；高亮框透明且不遮内容；练习计时与答案出现时机；制作标注、账号信息和占位是否清理。

从导出MP4抽帧，不只看渲染源图。验证报告留在制作侧，交付简述文件、片长、主时间线位置和待确认事项。


## 动效与标注细节

- 需要连续动作时逐帧更新，不能用低帧率位移动作装进30 fps文件冒充流畅。静态背景可缓存，活动元素保持目标帧率并使用合适缓动。
- 标注框从实际截图区域计算，经过裁剪、缩放、平移后同步转换坐标。核对框是否包围目标、文字是否居中、边距是否够，而不是只检查框存在。
- 解释不同动作应使用对应的素材或清楚的动作示意。不能把同一张打电话图反复改标签，声称已演示拿手机、读屏和接听三个动作。
- 展示软件时间线与说明性时间图要有可辨别的上下文，不能把虚构图伪装成真实界面或操作结果。
- 飞书表格、宽图和虚拟滚动内容需逐区检查；只看首屏不代表课件完整。发布后验证正文、图片和权限实际可访问，不把创建成功等同于内容正确。
